POG Studio

A personal tool by Garadron

POG Studio runs on its operator's own computer. After a live stream it cuts highlight clips from the operator's own recordings, lets the operator review them, and sends the approved ones to the operator's own social accounts: as drafts on TikTok, as Reels on Instagram and as Shorts on the operator's YouTube channel. For the clips already published it shows the operator how they are doing (views, likes, comments).

It is not a public service: nobody else can sign in to it or use it.

POG Studio uploads the approved clips to the operator's YouTube channel and reads their statistics through YouTube API Services. How it uses YouTube data is described in the Privacy Policy; using it means agreeing to the YouTube Terms of Service.
